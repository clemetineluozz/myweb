动画作品

三件小东西：一颗自己转的地球、一只往上飘的气球，和一束扫过字面的光。全部由 CSS 关键帧完成，没有引入任何库。

关于原来的 Flash 版本

这门课的原始素材里，动画是 .swf 文件，靠 Flash 播放器驱动。Flash 已于 2020 年底停止支持， 现代浏览器不再加载它，所以这里没有直接放 .swf， 而是把「地球 / 气球 / 光线」三个镜头用 CSS 动画重做了一遍——效果能跑在任何手机和电脑上，也不需要装插件。

地球

第 1 件 · 循环 16s

大陆用多层径向渐变叠出来，整体放在一个圆形裁切里缓慢旋转；外侧虚线轨道上挂着一颗小卫星。

用到的属性：border-radius · radial-gradient · @keyframes spin

气球

第 2 件 · 循环 5s

气球本体是一个圆角不均匀的椭圆，下面接一个三角形气嘴和一根渐隐的细线；上下浮动用位移加轻微旋转，云朵则横向循环漂移。

用到的属性：border-radius 多值 · transform · animation-delay

光线掠过

第 3 件 · 循环 4.6s

光线掠过

background-clip: text

文字本身是渐变色块裁出来的，让背景色块横向移动，就得到「光从字上扫过去」的观感；再叠一层斜向光带加强节奏。

用到的属性：background-clip: text · background-position · filter: blur

how it works

三段动画的共同点

看起来是三件事，做法其实是同一套：给一个元素定好起点和终点，然后让浏览器补中间帧。

只动两个属性

旋转和位移。动 transform 不会触发重排，比动 left、top 更省性能，也更不容易卡。

错开节奏

三只气球用不同的 animation-duration 和负的 delay，动作就不会整齐得像队列，看着更自然。

尊重系统设置

当系统开启「减少动态效果」时，页面会通过 prefers-reduced-motion 把动画几乎停掉，不让人头晕。
