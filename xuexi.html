学习心得

从「用表格拼一张网页」到「写一份能放到手机上的页面」，踩过的坑基本都在这里。五条，按踩到的先后顺序排。

01

先把结构写清楚，再谈好看

教程里的做法是用一张 4 行 2 列的表格，靠合并单元格拼出版式。能出效果，但表格是「数据」的语义， 拿它当骨架，读屏软件会念成一堆行列，改一个间距还得动整张表。 重做时我换成了 header、nav、main、aside、footer， 布局交给 Flexbox 和 Grid——结构没变，但改版时只需要动 CSS。

02

相对路径，是「换台电脑就找不到图」的真凶

被这个问题坑过两次。第一次是把 D:\MYWEB\images\logo.jpg 这种绝对路径写进了 src， 本机好好的，拷给同学就全变成裂图；第二次是文件名大小写——Windows 不在乎 MAO.jpg 和 mao.jpg，GitHub Pages 跑在 Linux 上却很在乎。 现在的规矩：只用 images/xxx.jpg 这样的相对路径，文件名一律小写。

03

Flash 退场了，但「做动画」的需求还在

原素材里那些 .swf 现在已经无法播放。与其怀念插件，不如记住它当年解决的问题： 让静止的页面动起来、有反馈。这件事现在交给 CSS 的 @keyframes、transform 和一点点 JavaScript。 我在「动画作品」里把地球、气球、光线重做了一遍，文件小、加载快，手机也能看。

04

颜色少一点，留白多一点

第一版首页用了红、蓝、绿、黄、灰五种颜色，像过年。后来把主色收成一个暖红， 配一个墨绿做点缀，其余全部交给米白和灰褐——页面立刻安静下来。 同一个道理也适用于字号：先定三个层级（标题、正文、注释），比随手写一堆 font-size 稳得多。

05

给键盘用户、慢网速和晕动症留一条路

好看不该以「别人用不了」为代价。所以：图片都写了 alt，次要图片用 loading="lazy"； 焦点用 :focus-visible 描出来，Tab 键走一圈能看到自己在哪； 系统开了「减少动态效果」时，动画会自动收敛。这些几乎不花时间，但差别很大。

这个站里已经做到的事

  • 六个页面，共用同一套导航与页脚
  • 全部使用相对路径，整包可移动
  • 手机、平板、桌面三档断点
  • 语义化标签与跳转链接
  • 图片有替代文字，懒加载
  • 动画尊重系统设置
  • 无 JavaScript 时内容仍可读
  • 零外部依赖，断网也能打开

接下来想学的

把「会写页面」变成「会写能维护的页面」，还差这些：

  • CSS 变量与设计令牌的整理
  • 用 Grid 做杂志式排版
  • 无障碍审计（读屏实测）
  • 一点点构建工具与部署流程
  • SVG 手绘与动效
  • 把笔记写成能复用的组件
教程给你的是「怎么做」，练习要回答的是「为什么这么做」。想明白一次，就不用再抄第二遍。 —— 课程结束时的自我总结
